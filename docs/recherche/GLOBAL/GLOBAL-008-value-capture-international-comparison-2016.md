## Zusammenfassung
Internationaler Vergleich von Value Capture Instrumenten in Asien, Europa, Nordamerika, Ozeanien und Lateinamerika. Analyse der Wirksamkeit je nach institutionellem Kontext.

## Key Findings
- Analyse zeigt unterschiedliche Wirksamkeit je nach institutionellem Kontext
- Länder mit traditionellem Landmanagement (z.B. European systems) fangen Bodenwertsteigerungen besser ab
